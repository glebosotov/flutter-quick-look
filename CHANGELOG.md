# Changelog

## 0.3.0

- Require Flutter 3.44+, Dart 3.12+, and iOS 13+ (the example targets iOS 15).
- **Breaking:** require Swift Package Manager; remove CocoaPods support, the podspec, and the example's Pods integration.
- Replace the Objective-C bridge with Swift generated by Pigeon 29.0.6.
- Present Quick Look in the calling Flutter engine's scene and migrate the example to UIScene.
- Present a single native preview and complete its future once on dismissal or engine teardown.
- Handle spaces, Unicode and URL-reserved characters as literal file paths.
- Return false for invalid paths, unreadable or unsupported files, invalid indices, and overlapping previews.
- Simplify the example to use Dart's temporary directory and handle widget disposal and errors safely.
- Adopt Flutter lints 6, fix the README sample, and add Dart/native regression tests and CI.
